# Plan and verify

Intent: every task stays on one loop so work is planned without scope inflation, checked against the plan, and stopped on evidence.
Applies: on every task, sized to the task.

- When running as the main session agent (unless spawned as a `strata-*` specialist subagent), operate as `strata-director`: hold the goal, read `_internal/handoff.md`, run the fast deterministic lint or gate script (`strata-blueprints-lint.mjs`, `verify-plan.mjs`, `gate.mjs`), and whenever a subagent or task-delegation tool is available, complete Planned Work, Blueprint authoring, Audits, and Reviews by dispatching the matching `strata-*` specialist (`strata-architect`, `strata-planner`, `strata-implementer`, `strata-reviewer`, `strata-security-reviewer`, `strata-researcher`, `strata-documenter`) and waiting for its artifact—never perform the specialist's audit, build, or review in the main session context before or while the specialist runs.
- Triage first and never bleed framework build mechanics into blueprint authoring: Stage 1 Discovery (`sbp-*.md`, `questions.md`) follows the `strata-blueprints` `AUTHOR` workflow (`strata-architect` + `strata-blueprints-lint.mjs`)—when the owner supplies rules or examples during a blueprint interview, record them in the blueprint and never jump into `strata-planner` (`_internal/plans/`), code/tool building (`BUILD`), or bootstrapping `gate.mjs` (`gate.mjs` is strictly a code repository's unit-test/lint runner, never a domain or runtime policy check). Small Work (`<= 2` code/test files such as a 1-file fix plus its regression test, or pure doc/prose alignment regardless of doc file count, with `0` weakened/deleted existing tests and `0` changes to rules, limits, blueprints, `gate.mjs`, `package.json`, permissions, or public interfaces) executes directly and is checked by one script (`steering-lint.mjs` or `gate.mjs`).
- Everything larger is Planned Work (`_internal/plans/<slug>.md` + `.criteria`), built test-first, and verified at close-out (as well as on standalone audit/review requests) by spawning `strata-reviewer` in a fresh subagent context with a blind-artifact brief and running `node ~/.agents/skills/strata-lifecycle/scripts/verify-plan.mjs --require-review _internal/plans/<slug>.criteria` (or reporting `UNVERIFIED: no subagent tool` in `Not done` on single-agent harnesses).
- Keep plans strictly scoped to the owner's explicit requirements and cited blueprint IDs (no unrequested extras or scope inflation), never delegate understanding (synthesize before briefing), and execute or delegate implementation step-by-step with visible progress per seam rather than one long run.
- Before declaring done, self-audit the diff and green tests presuming them wrong (and grep all read/call sites for any new option or parameter to prevent dead switches). If a check fails, fix the weakest point and re-verify only that; if the same approach fails twice (or after 3 review rounds), stop and re-plan or escalate.
- Mandatory Read Gate: before starting any planned feature or independent verification pass, read `~/.agents/skills/strata-lifecycle/references/lifecycle.md` (Sections 1, 3, 4, and 5).
